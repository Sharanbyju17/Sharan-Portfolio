# Sharan Byju Portfolio

A modern React + Vite portfolio created from the supplied resume and profile photo.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Customize

- Profile image: `public/profile.png`
- Resume download: `public/Sharan_Byju_Resume.docx`
- Portfolio content: `src/App.jsx`
- Design/theme: `src/styles.css`
